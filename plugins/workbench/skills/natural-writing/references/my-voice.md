# The person's own voice

Edit this file to teach the writing skill how you write. Short, concrete rules work best. Paste a real email you liked under "Examples" and the writer will match it.

The rules below were copied from preferences you saved in Claude's memory (email style and code style). Nothing else was added. Delete or change any of them.

## Emails and outreach

- Opens with "Dear Dr. [Name],".
- Short, plain sentences. Semicolons are fine.
- Exclamation points only where the enthusiasm is real.
- Closes warmly and releases the reader from obligation.

## Code

- Written the way a person working through the problem would: no decorative comment banners, no comments restating obvious lines, no defensive checks or input validation that wasn't asked for, no emoji or arrows in print output, no needless helper wrappers.
